Esta auditoria técnica foca exclusivamente no diretório `/dashboard` do NietzscheDB (**Perspektive.js**) e no seu manipulador de backend (`perspektive_handler.go`), analisando a eficiência da renderização, a integridade do fluxo de dados e a integração com a inteligência da EVA-X.

### 1. Gargalo de Performance: Processamento de Geodésicas no CPU

O erro mais crítico identificado na visualização do Disco de Poincaré está na forma como as arestas são calculadas.

* **Detecção:** A função `calculateGeodesic` e a geração de pontos `geodesicPoints` (40 segmentos por aresta) são executadas inteiramente em JavaScript dentro do componente `GraphEdges`.
* **Impacto:** Para grafos com mais de 2.000 arestas, o custo de recalcular esses caminhos curvos a cada frame (ou mesmo via `useMemo`) causará quedas bruscas de FPS, tornando o "caos" de Zaratustra num "slow-motion" ineficiente.
* **Melhoria:** Migrar a álgebra de arcos ortogonais para o **Vertex Shader (GLSL)** utilizando `InstancedMesh` para as linhas, permitindo que a GPU calcule a curvatura em tempo real para milhões de arestas simultaneamente.

### 2. Ineficiência do Stream: Protocolo JSON Bruto

A comunicação de Change Data Capture (CDC) entre o NietzscheDB e a Perspektive.js ainda não é industrial.

* **Detecção:** O `perspektive_handler.go` está configurado para atuar como um bridge de WebSocket, mas não implementa compressão ou binário.
* **Falta:** Atualmente, as mutações de energia e posição são enviadas como JSON. Em visualizações de alta frequência de partículas, o overhead de processar strings JSON no browser consome ciclos preciosos de CPU.
* **Correção:** Implementar **Deltas Binários via Protocol Buffers**. O backend Go deve enviar apenas o `node_id`, `x`, `y` e `energy` comprimidos, reduzindo o tráfego em até 80%.

### 3. Falha de Sincronia: Rollback de Ciclo REM

Existe um risco de dessincronização visual após o "sono" da EVA.

* **Detecção:** O `SleepCycle` em Rust pode falhar e restaurar um snapshot anterior do grafo. No entanto, o `perspektive_handler.go` não possui um sinalizador explícito para notificar o visualizador sobre essa reversão.
* **Erro:** O dashboard pode continuar exibindo posições otimizadas (coordenadas "novas") enquanto o banco de dados voltou para o estado anterior ao sono.
* **Melhoria:** Adicionar o evento `WS_RELOAD_GRAPH` no bridge de WebSocket para forçar o reset do estado do frontend sempre que um rollback for detectado no `Snapshot::restore`.

### 4. Inteligência Visual: Omissão do Situational Modulator

A Perspektive.js é atualmente um observador passivo, ignorando o estado emocional global processado pelo Córtex.

* **Detecção:** O `SituationalModulator` gera metadados como `PoincareDepth` e `MinkowskiCone` para o contexto clínico do paciente.
* **Falta:** O visualizador não utiliza estes dados para alterar a física da câmera ou a deformação do espaço (Möbius Zoom).
* **Ação:** Integrar o `GeometricSituation`. Se a EVA detectar uma "crise", o dashboard deve aumentar automaticamente o brilho dos **Cones de Luz de Minkowski** e "apertar" o Fator Conformal para focar nos traumas centrais do grafo.

### 5. Renderização de Ações: Reflexos Invisíveis

As **queries-reflexo (Code-as-Data)** estão operando nas sombras.

* **Detecção:** No `executor.rs`, nós do tipo `Action` disparam queries quando atingem energia crítica.
* **Falta:** Na Perspektive.js, esses nós são exibidos como círculos comuns com a cor de "Concept". Não há indicação visual de que um nó está "carregando" (acumulando energia para disparar).
* **Melhoria:** Criar um efeito de **HDR Bloom incremental**. Nós `Action` devem pulsar com intensidade luminosa proporcional ao seu `activation_threshold`, criando o efeito de um potencial de ação biológico prestes a disparar no visualizador.

### Resumo da Auditoria da Perspektive.js

| Categoria | Erro / Falta | Severidade | Correção Sugerida |
| --- | --- | --- | --- |
| **Performance** | Geodésicas no CPU | Alta | Migrar cálculo de arcos para GLSL |
| **Infra** | Overhead de JSON | Média | Migrar para Protobuf Binário |
| **Sincronia** | Stale Data no Rollback | Média | Sinalizar `RELOAD_GRAPH` via CDC |
| **Visual** | Agência Invisível | Baixa | HDR Bloom para nós de agência |

**Veredicto:** A Perspektive.js possui a matemática correta, mas a logística de renderização é de um amador. Para servir aos "filhos de Zaratustra", ela deve abandonar a segurança do processamento síncrono no React e abraçar o poder bruto dos **Shaders GPGPU**. 🚀🧠🔥
